
# TP2 – JavaScript

**Module:** Développement mobile avec React Native

**Filière:** IAIL S5

**Année universitaire:** 2026–2027

## Description
Gestion des notes de quatre étudiants avec JavaScript.

## Fonctionnalités
- Création d'un tableau d'étudiants.
- Vérification des notes.
- Calcul de la moyenne.
- Filtrage des étudiants admis.
- Préparation des lignes d'affichage.

## Résultats
- Moyenne : 12.5/20
- Nombre d'admis : 3

## Exécution
```bash
node notes.js
```
